# ブロックのたね

外部ライブラリ、CDN、ログインを使わない、段階的なビジュアルプログラミング学習環境です。

画面上部の「いまのお題」に、目標と難易度を表示します。探検マップには9つの秘境があり、各地で4題、全部で36題に挑戦できます。

| 難易度 | 取り組み方 |
| --- | --- |
| ★1 | 完成したお手本を動かして、どの命令が何をするのか観察します。 |
| ★2・同じお題 | ★1をクリアすると選べます。お手本で試した動きを、空のプログラムから再現します。 |
| ★2・次のお題 | 歩数やセンサーの条件などを変えた新しいお題を、白紙から組み立てます。 |
| ★3 | 白紙から複数の条件や操作を組み合わせて、最後のお題に挑みます。 |

★2と★3の「見本を見る」は、作りかけのプログラムを保ったまま開閉できます。「ヒントとクリア条件」で達成した条件を確認できます。★1・次のお題の★2・★3をクリアすると次の秘境が開きます。同じお題を再現する★2は、後からでも挑戦できます。

クリアしたお題にはそれぞれ王冠が付きます。再開時には作りかけの課題や次の未クリア課題が開き、クリアしたお題は「もう一度挑戦」や探検マップから遊び直せます。

### 経験値と称号

探検のお題を初めてクリアしたときの経験値は、★1のお手本が20 XP、★2の同じお題を白紙から作ると30 XP、★2の応用が40 XP、★3が60 XPです。同じお題に再挑戦してクリアすると、前回の半分（小数点以下切り捨て、最低1 XP）がもらえます。1回の挑戦で「うごかす」を何度押しても、経験値をもらえるのは1回です。

最初は20 XPでレベルが1つ上がります。Lv.6からは30 XP、Lv.11からは40 XPと、5レベルごとに必要な経験値が10 XPずつ増えます。1つの秘境の4題を初クリアすると150 XPでLv.7、全36題なら1,350 XPでLv.31です。

各秘境の★3をクリアすると称号が手に入り、画面上部に表示されます。レベル表示を押すと、経験値と、称号ごとに身につけた技を見返せます。獲得した称号から好きなものを選んで表示できます。以前の王冠も初クリア分の経験値と称号に反映され、同じブラウザーで引き継がれます。

パタゴニアでは歩数を変えて観測ルートを描き、ナミブ砂漠では曲がる角度と回数を組み合わせます。屋久島では木かげ・日なたや人の有無を切り替えて、プログラムで決めた条件でランタンが光るかを調べます。

次の6つの秘境では、命令を加えて順番と条件を決め、「うごかす」でイラストの変化を観察します。「場面をかえる」で別の初期条件も試せます。★3では、同じプログラムを2つの場面で続けて動かし、両方でお題を達成すると王冠が付きます。

| 秘境 | プログラムで挑戦すること |
| --- | --- |
| グヌン・ムル洞窟 | 手をたたいた音にこだまを返し、最後は音と休みの並びを記録して再生します。 |
| ガラパゴス諸島 | カメと岩を見分け、立ち止まったゾウガメも1匹につき1枚だけ撮ります。 |
| ウユニ塩原 | 空の星を水面に映し、星が動いても上下対称の星座を作ります。 |
| パラオのロックアイランド | 潮位を読んで小舟を進め、二つの浅瀬をこえて島に荷物を届けます。 |
| アオラキの星空 | 望遠鏡を星に向け、雲がかかったら待って晴れた写真を集めます。 |
| マクマード・ドライバレー | 観測車で三つの旗をめぐり、電池に合わせて走り方を変え、土の記録を基地に届けます。 |

ブロックを選んでからパレットをタップすると、その位置に命令を追加できます。矢印キーで選択、Alt＋上下で並べ替え、Ctrl／⌘＋Zで元に戻せます。スマートフォンでは「ブロック」「プログラム」「ステージ」を切り替えて操作します。前回の作品は起動時に復元し、「作品と保存」から別の作品や新規作成を選べます。

## 起動

ES Modules と Service Worker を使うため、配布先では HTTPS で公開します。手元では `blockseed` フォルダーを静的HTTPサーバーで配信してください。初回表示後は Service Worker によりオフラインでも動きます。

## 授業向けURL

- `?level=3`：使える道具のレベルを3にして開く
- `?level=3&lock=1`：使える道具のレベルを3に固定する
- `?teacher=1`：先生モードを使う
- `?level=2&lock=1&easy=1`：レベル固定＋削除確認を増やす

ヘッダーの山のマークを5回押しても先生モードを開けます。

## 自己テスト

静的HTTPサーバーから `tests/index.html` を開きます。外部テストランナーは不要です。
`node --test tests/*.test.mjs` で実行エンジン、探検の進行、各お題の判定をテストできます。`python tests/static_check.py` で配布サイズとオフライン用ファイルを確認できます。

## 1枚版

`python tools/build_single.py` を実行すると `dist/blockseed-single.html` が作られます。1枚版は配布用で、PWA更新機能は含みません。

## 公開用ファイル

`python tools/build_site.py` で、外部依存のない公開用ファイルを `dist/` にそろえます。
